# Grocery Price Per Unit

Safari userscript for sorting grocery prices by weight, volume, count, or total price.

[Install userscript](https://raw.githubusercontent.com/nabekhan/grocery-price-per-unit/main/dist/Grocery-Price-Per-Unit.user.js)

## Sites

- Walmart Canada
- Real Canadian Superstore
- No Frills
- Save-On-Foods

## Development

```sh
npm ci
npm run check
```
